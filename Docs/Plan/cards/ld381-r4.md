# Card ld381-r4: LobbyDaemon NP (Sts) calls and notifies, charge, grade, slots, second password, mileage, auction

## Goal
Every NP message of the 381 dispatch has a Rust path. The jobs that wait for NP (start sequence, slots, second password, charge, grade, mileage, auction, play reward) run to their end. A feature that is off in the config sends the original "off" code, as today.

## Work
Do the parts in this order. Each part ends with green tests. If the stage ends, the next session continues at the next part.

1. **Part A — NP surface.** Add the `Np` methods and `NpEvent` of "Interfaces". Each default body returns the off code, so the old adapters compile. Implement them in the stub (fixtures) and in `lobbyd-sts.rs` where the StServers message is known; else return the off code and mark ❓.
2. **Part B — start sequence.** `start` follows `18-jobs-f.md` §1 (state map lines 18–45, common rules 46–55): last presences, slots (list, create, set data), presence, profile, game time, grade level and all grades, bans, RMS, promotion status, initial name check. A step whose config key is off is skipped as the spec says. `start_retained` adds the grade reload (`10-timers-refresh.md` lines 34–56).
3. **Part C — slots and second password.** `GetSlot` in create (44) and try enter (24). `BindCharacterSlotJob` (57) with `bind_character_slot` (DB). Second password jobs (gamed 80/83) and the second password steps of delete (47) and try enter (24).
4. **Part D — charge.** 60 on-path (`GetChargeInfoJob`), gamed 30/33/38 jobs, NP charge notifies (`20-handlers.md` lines 153–159), stop-play timer (`TimeoutStopPlay`), charge step of try enter.
5. **Part E — grade.** 106 on-path, gamed 92 and 97, NP grade notifies → gamed 95/96.
6. **Part F — mileage.** `DepositMileageJob` from gamed 100, manage 14 and the timers `MileageBatchRetryDeposit` and `MileageInterimDepositTimer`; deposit id from `np::deposit_id` with `Settings::np_game_code`; mileage wrappers; LobbyGate Hello fever list when `enable-mileage` is on.
7. **Part G — auction.** gamed 87/88/89, NP auction messages, auction wrappers, `PostOffice` off adapter (posts fail with the off code; the jobs then take their fail path).
8. **Part H — other.** gamed 17, 78, 79, 104 (`TakeAccountTimeBasedPlayRewardJob`), `SetupNpScheduleInfoJob`, NP log-only messages (`20-handlers.md` lines 42–47), `SrvAuth_IsUserNameChangeableIncomplete` / `GetUserNameChangeableIncomplete` for the `ChangeUserNameJob` hook of `ld381-r2`.
9. Add the r4 config keys (`25-rust-coverage.md` §10) to `Settings`; all feature keys default off.
10. Write the result into `25-rust-coverage.md` (r4 rows).
