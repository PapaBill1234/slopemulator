# Card ld381-r5: LobbyDaemon database — guild names, jumping state, name rules, error maps, time conversion, live SQL

## Goal
The last `LobbyDB` wrappers have Rust code (guild names, jumping character state). Name rules come from the config. Each wrapper caller maps `dbrtn` to the wire code of the spec. SQL times convert in one place. The operator can run the live SQL tests with one command.

## Work
1. Packet crate: gamed variants 45–55, 72–77. Extend `message_round_trip`.
2. Store: the 8 r5 wrappers (`TryGuildRegistration`, `FinishGuildRegistration`, `CancelGuildRegistration`, `DeleteGuild`, `TryRenameGuild`, `FinishRenameGuild`, `CancelRenameGuild`, `UpdateJumpingCharacterStateComplete` with its 2 procedures) in `Store`, `SyncStore`, `MemoryStore`, `MssqlStore`. Bound parameters only (D1–D5).
3. Guild handlers (`20-handlers.md` lines 123–133): the world must be registered (else 2); name check; DB call; reply 46/47 or 51/52. Notifies have no reply. Each DB call runs in a job task, not in the link task.
4. `UpgradeJumpingCharacterStateJob` (gamed 72 and 75, `19-jobs-g.md` lines 93–113).
5. `src/name_rules.rs`: one `NameRules` for character, guild and user names from the r5 config keys (`allowed-*`, `enable-multilingual-for-*`, `enable-numeric-for-*`, `forbidden-characters-for-*`, `force-sentence-case-for-*`, `support-languages` ❓). `CharacterPolicy` uses it. The result codes come from `19-jobs-g.md` lines 63–73 and `11-character-select.md` lines 342–400.
6. Error maps: write one function per caller group (`src/db_codes.rs`) that maps `dbrtn` to the wire code, from `08-db-binding.md` lines 76–145 and the job specs. A `dbrtn` with no spec row maps to 2 and logs the value (❓ in the code). Replace the local R15 codes where the spec has a value.
7. Time conversion: one function converts SQL `datetime` to `SystemTime` with `Settings::sql_utc_offset` (default 0 = UTC host, argument `--sql-utc-offset <minutes>`). `MssqlStore` reads and writes through it. `SqlTimestamp::to_system_time` uses it.
8. Deletion keys: `short-term-character-deletion-time`, `long-term-character-deletion-time`, `long-term-character-deletion-criteria-level`, `wait-character-deletion` choose the wait time as `16-jobs-d.md` §2 says. `store-game-account-name`, `store-user-ip-address` control the login writes (`08-db-binding.md` contracts of `RegisterGameAccount`, `UpdateLastLogin`).
9. Live SQL: keep `tests/mssql.rs` operator tests; add the new wrappers to them; they skip when `LOBBYD_MSSQL_URL` is not set. Write the operator command in the handoff.
10. Write the result into `25-rust-coverage.md` (r5 rows and X8–X10).
