# Card ld381-r3: LobbyDaemon manage port, InfoGate, world registry and queue, timers, config file

## Goal
LobbyDaemon has the manage listener, the InfoGate listener, a world registry from the database with the world wait queue, the game time scheduler, the link reconnect timer and a config file loader. The LobbyGate Hello checks the peer table.

## Work
1. `src/config.rs`: read `lobbyd.config.xml` (option names of `01-config.md` lines 49–211) into `Settings`. Arguments of `main.rs` override the file. Unknown and out-of-scope keys are logged once. Never log a value of `cert` or an address.
2. Map the partial keys of card r3 (`25-rust-coverage.md` §10) and the 21 missing r3 keys to `Settings` fields.
3. `src/registry.rs`: `WorldRegistry` from `load_game_world_clusters` and `load_game_worlds`. Period `world-info-list-update-period`. A larger max player count starts `EndWaitGameWorldJob` for queued sessions (`13-jobs-a.md` lines 84–95). `--world` stays a fixture for tests.
4. World wait queue in `LinkGameDaemon::admit`: when the world is full, return an `Admission` with `WaitInfo` (state 3.2). Keep `GetWaitInfoReq` and `GiveupWaitReq` tests green. Bot and grade priority keys as `20-handlers.md` §9 and `01-config.md` say; if the order rule is not in the specs, use first in, first out and mark ❓.
5. `src/manage.rs`: manage listener (`manage-port`). Hello `hhh` with version 7 → `h` (2); failure `hh` (3, reason) and close. 4 → broadcast to all LobbyGate links. 5 → `KickJob` with the manage demander (session by account → else 4). 8 and 11 → remove the index entry (else 4). 14 → code 2 until `ld381-r4`.
6. `src/infogate.rs`: InfoGate listener (`info-gate-port`, `use-info-gate`). Hello → world list `hiChhQ;`. 4 → session by client key (else 4), token = `_infoGateToken` of the session (else 15). The session gets a random 16-byte InfoGate token at login ❓ (find the issue step in `18-jobs-f.md` §1; if not found, mark ❓). 7 → world list. gamed 103 `hhsh` → broadcast to InfoGate links.
7. LobbyGate Hello: check the peer against the peer table (`reserved-lobby-gate-wid-range-*` and the address, `20-handlers.md` line 24). Duplicate gate id → close both.
8. Timers: `GameTimeScheduler` (168 hourly queues, `20-handlers.md` line 169), reconnect timer for the account inventory link, `LobbydReloadInvalidRestoreTimer` (body ❓: add the timer with no work and a log line, mark ❓). Each timer is a task with a `shutdown` token, as `Server::spawn_deletion_scheduler`.
9. Write the result into `25-rust-coverage.md` (r3 rows).
